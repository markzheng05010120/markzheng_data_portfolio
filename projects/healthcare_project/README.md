# Healthcare Stroke Prediction Analysis

## Project Goal
Explore which health and lifestyle factors are associated with stroke risk.

## Dataset
Healthcare stroke dataset.

Variables include:

- gender
- age
- hypertension
- heart_disease
- ever_married
- work_type
- residence_type
- avg_glucose_level
- bmi
- smoking_status
- stroke

## Project Structure

data/raw  
Original dataset

notebooks  
Exploratory data analysis and modeling

outputs  
Charts and analysis results
